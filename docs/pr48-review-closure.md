## Purpose and confidence

This ledger consolidates the supplied assessment with the live GitHub review artifacts, maps duplicate comments to shared findings, records relevant implementation evidence, and separates source changes from actual acceptance. An item tagged **Fixed in source; validation pending** is not an assertion that CI or the complete fault matrix passed. This ledger was prepared while portable and Windows GitHub Actions runs were executing; their final results must be recorded after completion. Native Windows UI, real installed-game authentication/injection and live historical plugin-binary compatibility remain external acceptance gates.

Four dispositions are used throughout:
- **Actionable** — code changes, tests, or evidence are still needed.
- **Fixed** — the specific defect is addressed in source; remaining acceptance caveats are explicitly stated.
- **Deferred** — intentionally outside this PR's current scope.
- **Blocked** — cannot be fully accepted with available test credentials, binaries, or native environment.
